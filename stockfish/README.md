# Stockfish (local install)

The Stockfish binary is **not stored in git** — it is ~109 MB and exceeds GitHub's 100 MB file limit.

## Setup

1. Download Stockfish for Windows (AVX2) from [stockfishchess.org/download](https://stockfishchess.org/download/) or the [official releases](https://github.com/official-stockfish/Stockfish/releases).
2. Place the executable in this folder as:

   `stockfish-windows-x86-64-avx2.exe`

The brilliance pipeline (Stages 2–3) expects that exact path relative to the repo root.
